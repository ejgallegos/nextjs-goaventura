# GoAventura

GoAventura es una aplicación Next.js para alojamientos, excursiones y viajes. El contenido público se mantiene en datos locales versionados y se despliega con Docker Compose.

## Desarrollo

```bash
npm run dev
npm run typecheck
npm run lint
npm run build
```

La administración de contenidos permanece deshabilitada hasta definir un proveedor de autenticación y persistencia independiente.
