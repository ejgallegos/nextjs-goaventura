# GoAventura

Sitio web de GoAventura, construido con Next.js y desplegado mediante Docker Compose.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run typecheck
npm run lint
npm run build
```

## Operación de disponibilidad

La instalación, migración, backups/restores de PostgreSQL y registro seguro de
fuentes Booking ICS están documentados en
[`docs/availability-operations.md`](docs/availability-operations.md).
